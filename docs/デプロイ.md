## 本番環境のマイグレーション

Renderの無料プランでは Pre-Deploy Command を利用できないため、
Start Commandでマイグレーション後にAPIを起動する。

### Build Command
```bash
go build -o bin/api ./cmd/api && go build -o bin/migrate ./cmd/migrate
```

### Start Command
```bash
./bin/migrate && ./bin/api
```

- デプロイ時だけでなく、再起動やスリープ復帰時にも実行されてしまう
- 同じAPIを複数台起動する場合、すべてが同じマイグレーションを実行しようとする
- 一方、Pre-Deploy Commandなら、APIインスタンスの起動とは別にデプロイ処理として1回だけ実行できます。

> Start Command：APIが起動・再起動するたびに実行される  
> Pre-Deploy Command：デプロイ時に1回だけ、API起動前に実行される


### React RouterのRewrite設定

MeetingPilotではReact Routerによるクライアントサイドルーティングを使用している。

Renderは通常、リクエストされたURLに対応するファイルを探すため、
`/meetings/123` などへ直接アクセスまたは再読み込みすると404になる。

すべての画面URLで `index.html` を返し、その後React Routerにルーティングさせるため、
RenderのStatic Siteに以下を設定する。

- Source: `/*`
- Destination: `/index.html`
- Action: `Rewrite`

これにより、直接アクセスや再読み込みでもReact Routerの画面が正常に表示される。
