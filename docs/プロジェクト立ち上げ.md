# フロントエンド

- React立ち上げ
```bash
npm create vite@latest frontend -- --template react-ts
# ESlintを選択
```

- ReactRouter導入
```bash
npm install react-router-dom
```

- TailwindCSS導入
```bash
npm install tailwindcss @tailwindcss/vite
```

- `vite.config.ts` 追記

- `src/index.css` 書き換え

- アプリ参考：https://qiita.com/Oyu3m/items/c5daff368bc75c79e7b0


# バックエンド
- Go立ち上げ
```bash
go mod init meeting-pilot
```

- ライブラリインストール
```bash
go get github.com/labstack/echo/v4
go get github.com/labstack/echo/v4/middleware
go get github.com/jackc/pgx/v5/stdlib
go get github.com/joho/godotenv

go mod tidy
```

# Docker

- PostgreSQL接続コマンド
```bash
docker exec -it meeting-pilot-db psql -U postgres -d meeting_pilot
```
